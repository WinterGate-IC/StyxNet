# Operations

StyxNet is operated as a defensive intelligence platform.

## Operational model

- Read-only collection of public sources
- Bounded concurrency and timeouts
- Validation before promotion
- Quarantine before deletion
- Audit logging for administrative actions

## Retention

- Active intelligence: confirmed records only
- Quarantine: three days for review
- Audit logs: retained for accountability
- Backups: controlled and access-restricted

## Safety controls

- Role-based access
- Token lifecycle and revocation
- Rate limits
- Health monitoring
- Explicit no-relay and no-unauthorised-access boundaries
